## 🚀 Featured Projects

### 🤖 Support Insights Agent
**Python · Django REST Framework · PostgreSQL · OpenAI Responses API · MCP**

An AI-powered support insights API that uses controlled, database-backed tools to search support tickets and analyze unresolved issues.

**Key features:**
- Built a Django REST API for support-ticket insights and analytics.
- Integrated the OpenAI Responses API to orchestrate tool-assisted workflows.
- Developed an MCP server using the official Python SDK to expose ticket search, analytics, and unresolved-issue analysis tools.
- Implemented schema validation and source-ticket ID verification to improve the reliability of tool outputs.
- Added input validation, sensitive-data safeguards, execution limits, and structured error handling.
- Created 13 natural-language evaluation cases to assess agent behavior.
- Added 16 Django tests covering application behavior.

**Focus areas:** AI integration, backend API design, controlled tool execution, database-backed analytics, validation, and testing.

### 🗺️ Route & Fuel Optimization API
**Python · Django REST Framework · PostgreSQL · Docker · Geoapify · Shapely**

An API that identifies cost-effective fuel stops along US driving routes, considering fuel prices, vehicle range, and fuel efficiency.

**Key features:**
- Integrated external geocoding and routing services.
- Implemented route-based fuel-stop optimization.
- Used PostgreSQL to manage fuel-station data.
- Added caching, structured error handling, and tests.
- Containerized the application with Docker.

**Focus areas:** Algorithms, geospatial computing, API integration, optimization, and data processing.
